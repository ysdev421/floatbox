# CLAUDE.md - もやもや解消PWA プロジェクト

## プロジェクト概要

頭の中のモヤモヤ（やらなきゃいけないこと・やりたいこと）を素早く吐き出し、整理・解消することに特化したPWAアプリ。

AIは使わない。UXの設計で差別化する。

---

## プロダクトコンセプト

### 解決したい課題
- やらなきゃいけないことが頭の中にぼんやり浮かんでいて言語化できていない
- 「やらなきゃ」と「やりたい」が混在してモヤモヤする
- 既存のタスク管理アプリは「すでに言語化できている前提」で作られていて合わない

### ターゲットユーザー
- ライフイベント（転職・結婚・引越しなど）が重なって情報過多になっている人
- 頭の中がいつもごちゃごちゃしている感覚がある人
- タスク管理アプリを試したが続かなかった人

---

## 設計の重点ポイント（優先順）

### 1. キャプチャの摩擦ゼロ
- アプリを開いたら0.5秒で入力できる状態
- カテゴリ・期限・優先度などの設定は後回しでOK
- 「吐き出すフェーズ」と「整理するフェーズ」を明確に分ける

### 2. 吐き出した後の「受け取られた感」
- 書いたものが消えずに残っている安心感を視覚で伝える
- これがないと脳が手放せない

### 3. やらなきゃ と やりたい を同じ場所で管理
- 2種類の性質が違うものを分けて管理できる
- ただし**入力は一箇所**（分類は後から）

### 4. 見返しのタイミングを設計
- 書いたまま放置すると結局モヤモヤが戻る
- 週1・朝晩など「整理するタイミング」をアプリ側から促す（プッシュ通知）

### 5. 完了の気持ちよさ
- チェックして消える瞬間の達成感でループを作る

---

## 技術スタック

- **形式**: PWA（Progressive Web App）
- **AI**: 使わない
- **フロントエンド**: React
- **ホスティング**: Vercel（GitHubと自動デプロイ連携）
- **バックエンド/DB**: Firebase
- **コード管理**: GitHub
- **通知**: Web Push API

## リポジトリ

- **リポジトリ名**: `floatbox`
- **構成**:
  ```
  GitHub（コード管理）
    ↓ push
  Vercel（ホスティング・自動デプロイ）
    ↓ API呼び出し
  Firebase（DB・認証）
  ```

---

## 差別化ポイント

既存アプリとの違い：
- 言語化できていない段階から使えるUX
- シンプルで速い（AIなし）
- 「やりたい」も「やらなきゃ」も一元管理
- モヤモヤ解消という体験にフォーカスしている

---

## 背景・参考概念

このアプリは以下の概念を解決しようとしている：

- **ツァイガルニク効果**: 未完了タスクが頭に残り続ける現象
- **メンタルクラッター**: 未処理のことが頭を占領している状態
- **認知負荷**: ワーキングメモリがパンパンになっている状態
- **GTD（Getting Things Done）**: 頭の中を全部外に出すことで脳の負荷を減らす手法

---

## 開発の進め方

1. まず自分（開発者）が使えるMVPを作る
2. 自分のモヤモヤが実際に減るか検証する
3. 良さそうなら少しずつ広げる

コストリスクを最小化するため、最初はAIなし・シンプルな構成でスタート。
